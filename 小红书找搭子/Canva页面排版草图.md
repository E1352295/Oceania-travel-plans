# Canva 页面排版草图

适用对象：`总帖 1 篇 + 分段帖 5 篇`  
适用尺寸：`1080 x 1440`  
整体方向：`硬核、直接、信息密度高，不做氛围感废话海报`

---

## 一套母版的核心思路

不要每页都重新设计。  
只做 `7 个固定母版`，后面复制替换文案和图片。

你这套图文最重要的不是“好看得像旅行杂志”，而是：

1. 2 秒内看懂这篇是哪个城市段
2. 5 秒内知道能不能 join
3. 看完立刻知道该怎么私信你

所以版式原则是：

- 标题大
- 信息块少但明确
- 每页只讲一件事
- 关键词和筛选句永远放在显眼位置

---

## 整套视觉设定

### 颜色

建议用这套：

- 主底色：`#F4F1EA` 米白
- 主文字：`#111111` 近黑
- 强调色 1：`#8E2C24` 铁锈红
- 强调色 2：`#2F4A3C` 军绿
- 辅助灰：`#D9D2C7`

用法：

- 背景大面积用米白
- 标题和正文用近黑
- 日期条、标签、重点字用铁锈红
- 分割线、图标、小标签底色用军绿或浅灰

不要用高饱和粉紫、小清新蓝、荧光色。  
这套内容更适合“野外手册感”和“路线卡片感”。

### 字体

Canva 里优先找这类：

- 标题：`思源黑体 Heavy / Noto Sans SC Black / 阿里妈妈方圆体`
- 正文：`思源黑体 Regular / Noto Sans SC`
- 数字和日期：`Bebas Neue / Oswald / Anton`

搭配方式：

- 中文标题用粗黑体
- 英文地名或日期可用窄体无衬线强化节奏
- 正文不要超过 2 种字体

### 元素风格

- 线条：用 1.5px 到 2px 细线
- 圆角：标签和卡片统一 `16-20`
- 阴影：尽量不用重阴影，只用轻微投影
- 图标：只用线性图标，如车、山、海浪、帐篷、消息

---

## 页面基础网格

所有页面统一用这个安全区：

- 画布：`1080 x 1440`
- 左右边距：`80`
- 上边距：`72`
- 下边距：`72`
- 模块间距：`24`

统一结构：

1. 顶部信息区
2. 中部主内容区
3. 底部筛选或 CTA 区

顶部建议保留一个小页码：

- 左上角：`P1 / 7`
- 样式：小号灰字，别抢标题

## 母版 1：封面页

### 用途

每篇第 1 页。  
功能是让人一眼知道：`时间 + 城市段 + 强度 + 你在找人`

### 版式结构

从上到下这样摆：

1. 左上：`P1 / 7`
2. 顶部横条：日期范围
3. 中间大标题：城市段名
4. 下方一行：3 个标签
5. 再下面：一句副标题
6. 底部：筛选句 + 私信提示

### 线框草图

```text
┌────────────────────────────┐
│ P1 / 7                     │
│ [ 4.23 - 4.26 ]            │
│                            │
│ 悉尼 / 蓝山                │
│ 找搭子                     │
│                            │
│ [徒步] [海岸线] [蓝山]      │
│                            │
│ 不是Citywalk               │
│ 是雨林穿越 + 悬崖海岸线     │
│                            │
│ 能早起、能暴走、能接受强度   │
│ 私信带日期来对              │
└────────────────────────────┘
```

### Canva 搭法

- 日期条做成横向胶带感色块，铁锈红底白字
- 大标题分两行，第二行写 `找搭子`
- 标签做成圆角小胶囊
- 副标题最多两行，不要写成长段
- 底部加一条细分割线，再放筛选句

### 封面配图建议

不要整页铺满风景照。  
更适合这两种做法：

1. 左下或右下放 1 张裁切风景图
2. 整页纯文字排版，只加 1 个地形纹理或噪点背景

总帖封面可用 `澳新地图轮廓 + 城市节点线`。  
分段帖封面可用 `当地代表景观裁切图`。

## 母版 2：这段到底玩什么

### 用途

每篇第 2 页。  
功能是快速定义这段的气质和门槛。

### 版式结构

1. 顶部主标题
2. 中间 4 条信息卡
3. 底部一句“不适合谁”

### 线框草图

```text
┌────────────────────────────┐
│ P2 / 7                     │
│ 这段到底玩什么             │
│                            │
│ ┌──────────────┐           │
│ │ 核心项目     │           │
│ │ 蓝山 / 海岸线 │          │
│ └──────────────┘           │
│ ┌──────────────┐           │
│ │ 强度等级     │           │
│ │ 中高强度      │          │
│ └──────────────┘           │
│ ┌──────────────┐           │
│ │ 适合什么人   │           │
│ │ 能连续走路的人 │         │
│ └──────────────┘           │
│ ┌──────────────┐           │
│ │ 不适合什么人 │           │
│ │ 纯拍照摆烂型  │          │
│ └──────────────┘           │
│                            │
│ 这段是自然线，不是松弛度假线 │
└────────────────────────────┘
```

### Canva 搭法

- 用 2 x 2 信息卡布局
- 卡片底色用浅灰或浅绿
- 每张卡只放 1 行标题 + 1 到 2 行内容
- 页面右上角可加一个小图标，比如山或海浪

## 母版 3：日期拆解页

### 用途

每篇第 3 页。  
功能是让别人快速判断自己能 join 哪几天。

### 版式结构

做成纵向时间轴最合适。

1. 左侧是日期
2. 中间是时间轴线
3. 右侧是地点 + 主活动

### 线框草图

```text
┌────────────────────────────┐
│ P3 / 7                     │
│ 这几天具体怎么走           │
│                            │
│ 4.24  ●  蓝山              │
│        │  Grand Canyon     │
│        │  Track 全天徒步    │
│                            │
│ 4.25  ●  皇家国家公园       │
│        │  Figure Eight     │
│        │  Pools            │
│                            │
│ 4.26  ●  悉尼机动恢复       │
│        │  Bondi to Coogee  │
│                            │
│ 能 join 一天也可以         │
└────────────────────────────┘
```

### Canva 搭法

- 用 1 条竖线贯穿 3 到 5 个日期点
- 日期数字用英文窄体字体，会更利落
- 右侧活动名加粗，说明用正常字重
- 每个日期点旁可加极简图标，如飞机、山、企鹅、海浪

## 母版 4：强度 / 预算 / 交通页

### 用途

每篇第 4 页。  
功能是筛人，这页一定要直接。

### 版式结构

做成四宫格最稳。

1. 强度
2. 预算
3. 交通
4. 住宿

### 线框草图

```text
┌────────────────────────────┐
│ P4 / 7                     │
│ 这段的门槛和现实条件       │
│                            │
│ ┌───────┐ ┌───────┐        │
│ │ 强度  │ │ 预算  │        │
│ │ 中高  │ │ 中高  │        │
│ └───────┘ └───────┘        │
│ ┌───────┐ ┌───────┐        │
│ │ 交通  │ │ 住宿  │        │
│ │ 自驾  │ │ 实用型│        │
│ └───────┘ └───────┘        │
│                            │
│ 不是最贵，但要求执行力在线  │
└────────────────────────────┘
```

### Canva 搭法

- 四宫格卡片尽量等宽等高
- 卡片标题小一点，核心结论大一点
- 每格里最多 3 行字
- 可以加 `强度条` 或 `预算条`，例如 5 格进度显示

例子：

- 强度：`■■■■□`
- 预算：`■■■□□`

这样别人会更快读懂。

## 母版 5：想找的搭子画像

### 用途

每篇第 5 页。  
功能是把“不合适的人”提前筛掉。

### 版式结构

做成 `5 条要求清单` 最直接。

### 线框草图

```text
┌────────────────────────────┐
│ P5 / 7                     │
│ 我想找什么样的搭子         │
│                            │
│ 01 守时，不放鸽子           │
│ 02 能早起，能转场           │
│ 03 体力别差太远             │
│ 04 消费观别差太远           │
│ 05 沟通直接，不内耗         │
│                            │
│ 不适合：纯拍照 / 睡到中午型 │
└────────────────────────────┘
```

### Canva 搭法

- 每条前面放大号编号 `01 02 03 04 05`
- 编号用铁锈红，文字用黑色
- 页面底部做一个 `不适合谁` 的反向标签条
- 不要写太委婉，这页越直越有效

## 母版 6：你本人画像页

### 用途

每篇第 6 页。  
功能是降低别人私信你的顾虑。

### 版式结构

适合做成 `左图右文` 或 `上文下文`。

如果你不想放真人照，就用纯文字版。

### 线框草图

```text
┌────────────────────────────┐
│ P6 / 7                     │
│ 我本人什么风格             │
│                            │
│ [可放一张局部旅行照/地图纹理]│
│                            │
│ [性别/年龄段]              │
│ 偏执行派                   │
│ 喜欢自然和徒步             │
│ 会提前做路线功课           │
│ 不爱无效折返               │
│                            │
│ 目标是找同频的人，不是凑数  │
└────────────────────────────┘
```

### Canva 搭法

- 如果放照片，照片只占页面 `30%`
- 如果不放照片，就做成 4 条人格标签卡
- 可以加 1 行小字：`不全程求搭子，只找能对上的人`

建议标签：

- `执行派`
- `自然向`
- `重体验`
- `讨厌拖拉`

## 母版 7：行动号召页

### 用途

每篇最后一页。  
功能是告诉对方“怎么来找你”。

### 版式结构

1. 顶部一句强 CTA
2. 中间放私信格式
3. 底部放优先回复规则

### 线框草图

```text
┌────────────────────────────┐
│ P7 / 7                     │
│ 想 join 的直接私信         │
│                            │
│ 请直接发我：               │
│ 日期                       │
│ 城市                       │
│ 能参加哪几天               │
│ 你的体力 / 风格 / 预算      │
│                            │
│ 优先回复：                 │
│ 说话直接、信息完整的人      │
│                            │
│ 收藏不如直接来对日期        │
└────────────────────────────┘
```

### Canva 搭法

- 中间做成 1 个大卡片
- 私信格式每行前面加小图标
- 页面最底部放一句催行动的话
- CTA 页不要放太多照片，纯信息最好

- Melbourne

4. 新西兰南岛

- 日期

## 图片使用建议

每篇最多准备 `3 张图`：

1. 封面主图
2. 玩法页辅助图
3. 本人画像页可选图

不要把每页都铺照片。  
这套内容更适合“文字主导，图片辅助”。

裁图建议：

- 海岸和山景用横图裁竖
- 企鹅、海豹、船、步道标识适合做局部特写
- 图片统一加 `10% 到 18%` 的暗色蒙版，保证字压得住

## Canva 实操顺序

直接按这个顺序搭最快：

1. 新建 `1080 x 1440` 文件
2. 先做 `7 页母版`
3. 统一设置颜色和字体
4. 先复制出 `总帖 7 页`
5. 再整份复制 5 次，改成 5 篇分段帖
6. 最后统一替换每篇封面图和关键词

建议先做这三个通用组件：

1. 日期条组件
2. 标签胶囊组件
3. 四宫格信息卡组件

做完后整套会非常快。

---

## 最后检查清单

导出前逐页看这 8 条：

1. 这一页标题是不是 2 秒能懂
2. 字有没有超过 3 种字号层级
3. 每页是不是只有 1 个重点
4. 标签颜色是否统一
5. 筛选句是否足够直接
6. 私信指令是否明确
7. 图片是否只是辅助而不是抢字
8. 每篇封面是否一眼看出 `城市 + 日期 + 强度`
