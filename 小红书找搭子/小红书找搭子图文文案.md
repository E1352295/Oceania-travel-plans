# 小红书找搭子图文文案

适用场景：按城市段拆分发小红书图文，目标是高效筛选能一起走一段的人。  
建议画布：`1080 x 1440` 或 `3:4 竖版`。  
建议做法：先做 1 套 Canva 母版，再复制 5 篇分段帖和 1 篇总帖。  

以下文案默认公开帖不放航班号、酒店全名、精确地址。  
以下带 `[]` 的内容建议你按本人情况替换后再发。  

## 统一版式

封面页固定放这 5 类信息：

1. 日期范围
2. 城市或区域名
3. 3 个关键词标签
4. 找搭子目的
5. 一句筛选句

正文页建议统一结构：

1. 左上角放页码，如 `P2 / 7`
2. 中间放 1 个主标题
3. 下方放 3 到 5 条短句
4. 页底固定放 1 句筛选提示，如 `高强度优先，不适合纯拍照型`

建议统一视觉方向：

- 风格：硬核、信息型、直接
- 配色：黑 / 白 / 暗红 / 军绿四选二
- 字体：标题用粗黑体，正文用简洁无衬线
- 图片：每篇只放 2 到 3 张代表图，不要每页都塞满照片

### Page 5 我想找的搭子
